# 参考归纳与首版版式

用户提供的参考包含清华紫、浙大蓝、北大红的文献组会模板、理工科多图排版与带顶部导航的开题模板。借鉴其信息组织：

| 内容任务 | 可借鉴结构 | 首版状态 |
|---|---|---|
| 首页与结束 | 校徽、主题色标题区、简短人员信息 | 已实现 cover / closing |
| 研究结果 | 大图＋侧栏解读＋一句话结论 | 已实现 evidence |
| 文献介绍 | 论文标题/截图与作者、来源并列 | 后续按需扩展 |
| 技术路线 | 步骤节点＋有意义的箭头＋方法说明 | 后续按需扩展 |
| 工作进度 | 阶段与完成状态，或甘特图 | 后续按需扩展 |
| 多图对照 | 图组标签、相同尺度、结论说明 | 后续按需扩展 |
| 章节导航 | 明确当前章的顶部或侧边标签 | 可选，首版未加入 |

宣传拼图中的编辑侧栏、网格、外部页序、贴纸、水印和推广标题不是幻灯片组件。示例中的研究结果不视作用户研究内容。

当前统一 960×540 逻辑画布，PPT 页面 13⅓×7.5 英寸，坐标除以72后转换为英寸，字号数值使用 pt。HTML 使用同数值逻辑 px 后整页缩放；打印时按 pt 输出。

主标题36、封面/尾页52、一般正文24、侧栏22、注释14作为首版起点。侧栏使用22以容纳两行简短说明，不能把长段落无限压缩。构建与浏览器检查均不自动缩字；超量时由作者或 agent 改写、拆页或扩展版式。

首版 evidence 只接收一张大图或一个标注清楚的素材位，以及最多三个侧栏要点。图像采用完整适配，不裁掉图例或坐标。它可以承载整组已标好的科研图，但图内文字清晰度仍需查看实际图像。

字体：中文 Noto Sans SC；普通英文 Times New Roman，HTML 缺少本机字体时回退衬线字体。官方校名组合保持原图；中文字体使用项目自带 OFL 字体，按当次内容制作子集。页内默认无冗余角标、灰色辅助线、装饰圆环、页脚页码，保留短主题色标题线、总结竖线和必要来源。
