# 校徽取色

默认输入为 `config/project.json` 的 `logos.color`，兼容 sharp 能解码的 PNG、JPEG、WebP、SVG 等。优先透明 PNG 或原始 SVG；不从参考宣传拼图裁出带背景的标识进行正式取色。

`src/theme.cjs` 在 sRGB 下将图像缩小到至多 384×384，用不透明的彩色像素统计颜色。排除 alpha <230、近白、低亮黑色及低饱和灰色；将相近颜色按 Lab 距离归并，保留簇中最常见的原始色作为候选，而非把边缘杂色平均成偏色。

这些阈值是当前工程启发式，不是学校视觉规范。彩色面积过小、极浅或半透明素材可能需要更好的源文件或手动覆盖。此方法适用于独立校徽，不保证能从复杂校园照片中找出学校品牌色。

两个明显候选同时占据足够面积时标记 `ambiguous`，仍给出推荐色与候选列表。只有黑白素材时标记 `monochrome`，透明或可见像素不足时标记 `insufficient`；两者使用明确标注的中性灰草稿。不会把中性灰称作官方校色。

配置优先级：手动 `primary` > 用户明确提供的 `officialPrimary` > 图像提取色 > 中性灰回退。两种显式色值均需 `#RRGGBB`。记录在 `palette.json` 中，不丢失原始提取结果。

主色保持取样值，`primaryText` 与 `deep` 通过加深获得浅底可读性，`pale` 和 `soft` 通过混白派生。正文和注释使用中性色；品牌背景上的文字根据对比度选择浅色或深色，不改动校徽本体。派生色不声称是官方标准色。

首轮北大素材提取主色为 `#9A0000`。此前手册中使用过的 Web 色值 `#94070A` 是另一条信息，本项目按本轮用户要求采用图像提取值。校徽来源记录于 `assets/logos/SOURCES.md`。
