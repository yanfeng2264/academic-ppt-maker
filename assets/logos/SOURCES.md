# 示例校徽素材来源

本项目复用前次已下载并检查的北京大学官方素材，未重新着色或拆分：

- `pku-lockup-color.png`：官方校徽与中英文校名横向彩色组合。
- `pku-lockup-white.png`：同一官方组合的反白版，预留供后续深色背景版式使用。
- `pku-emblem.png`：官方圆形彩色校徽。

来源：[北京大学标识管理办公室下载专区](https://vim.pku.edu.cn/xzzq/)。
组合素材：[官方 ZIP](https://vim.pku.edu.cn/docs/20240527144451726806.zip)；纯校徽：[官方 ZIP](https://vim.pku.edu.cn/docs/20240527144201516364.zip)。

这是用户要求制作的示例设计，不声称属于北京大学官方发布的模板。换学校时更换素材、校名和来源记录；图片取色不等于官方标准色认证。
